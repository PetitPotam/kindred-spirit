Install and set up

Hosting Pip means running the mod in Minecraft and her "brain" on the same computer, a Mac for now. Joining a friend who already hosts her is much simpler: see Friends on LAN.

What you need

  • Minecraft Java Edition, release 26.3 (the newest, recommended) or 1.21.1, with the Fabric loader: the setup installs Fabric for you.
  • A Mac with macOS 12 or newer, Apple silicon or Intel. Windows and Linux hosts aren't supported yet (they're on the roadmap).
  • An AI for her to think with. Use what you already have: a free Gemini key (the default; the Setup shows how to get one in about two minutes), an API key (OpenAI, Claude API, Groq, OpenRouter, Mistral), an AI subscription you already have (Claude Code, Codex, Gemini CLI), or nothing at all with Ollama on your computer.

The easy way: Kindred Spirit Setup

An app you download and open. It carries its own Python and opens a guide in your browser: each step explains itself, recommends a choice, has Test it, and Copy a help prompt for any AI assistant when something goes wrong.

  1. Download it for your Mac's chip from the Download page, drag it to Applications and open it. The first time, macOS warns you (the app isn't signed by Apple): the Download page shows how to open it anyway.

  2. Her brain: it looks at your Mac, picks settings that keep Minecraft smooth, installs her brain, the gateway and her dashboard in your user folder (no administrator password), and wakes her up.

  3. Her AI: for her conversation (System 1), and for her slow thinking (System 2: the same one, another, or off). Use this asks her a first question and shows the answer. Keys go in ~/.kindred-spirit/secrets.env, readable only by you, and are never shown again.

  4. Her instincts, voice and hearing, on your Mac, sized for it: bge-small, Kokoro with Hear it for each voice, and Whisper with a microphone test. Each download is checked and can resume.

  5. Minecraft: quit the Minecraft Launcher, and the Setup adds a Kindred Spirit (Fabric 26.3) profile (or 1.21.1) with Fabric Loader, Fabric API and the mod, in a game folder of its own. Your other profiles, mods and worlds are left alone. Using Prism, CurseForge or MultiMC? It can put the mod in that launcher's mods folder instead.

  6. Say hi to her: Open Minecraft, choose the Kindred Spirit profile, open a world and type "hi Pip" in the chat. The page sees her answer.

Later, the Setup's Updates step updates her brain, the mod and the Setup together, and can go back. Opening Kindred Spirit Setup again wakes her and opens her dashboard. Every step in detail: docs/SETUP.md.

A beta

The Setup is built and tested on GitHub's Apple silicon and Intel Macs with every release, with a stand-in AI. Nobody has yet tried it on a real Intel Mac, with real AI keys through the Setup, or updated it from one release to the next. If you do, tell us how it went.

By hand, from the source code

For contributors, or if you'd rather use a terminal. About ten minutes, with Homebrew.

  1. Install the tools Java, Python and the local speech-to-text:

    brew install openjdk@25 python@3.12 whisper-cpp

  2. Get the code

    git clone {{repo}}.git
cd kindred-spirit

  3. Run the setup guide

    scripts/setup.sh

    It prepares her brain, then asks what you have for each of the four parts: the AI (how she thinks), speech-to-text (how she hears you), the voice (how she speaks, or subtitles only) and memory (on your computer, or your own deployed gateway). It saves your choices, installs only the local tools you picked, starts everything and tests each part:

      ok   AI           Hello, friend, there!
  ok   voice        65 KB of WAV
  ok   speech->text heard: 'Testing 1 2 3.'
  ok   embeddings   384 numbers per text
  ok   memory       stored, found and removed a test memory

    Anything that fails comes with how to fix it. Your keys go in ~/.kindred-spirit/secrets.env, readable only by you. Want no questions? scripts/setup.sh --defaults picks Gemini and everything else local.

  4. Build the mod (one jar per Minecraft version, 26.3 and 1.21.1)

    (cd mod && ./gradlew build)

  5. Add a launcher profile (quit the Minecraft Launcher first):

    python3 scripts/install_profile.py --minecraft 26.3

    It adds a Kindred Spirit (Fabric 26.3) profile with its own game folder (minecraft-kindred-26.3), installs Fabric Loader and Fabric API, and backs up your launcher profiles. Without --minecraft, it's 1.21.1 (minecraft-kindred). Your other profiles, mods and worlds are left alone.

  6. Play Double-click scripts/play-mac.command. It starts everything and opens the launcher from Terminal. Pick the Kindred Spirit profile and press Play.

Why start from Terminal (or from the Setup)?

On macOS the Minecraft Launcher has no microphone permission of its own. Started from the Dock, the game records silence, so play-mac.command opens it from Terminal, which can use the microphone. With the Setup, start it with Open Minecraft: macOS then asks for the microphone in the Setup's name.

Changing your choices later

  • With the Setup: open it, then Setup steps in her dashboard's side bar.
  • By hand, run the guide again: brain/.venv/bin/python scripts/guide.py
  • Only test everything: brain/.venv/bin/python scripts/guide.py --check
  • Switch one part in one command, without restarting the game: see Configure her.

Optional: what she knows about Minecraft

Pip answers "how does this work?" questions from a knowledge base on your computer, built from the Minecraft Wiki and the game's own recipe data. You fill it yourself (the recommended set takes about 45 minutes, at a polite one page per second):

python3 services/knowledge/kb.py crawl minecraft-wiki --core --grow 600
python3 services/knowledge/kb.py crawl minecraft-data

She also learns pages she doesn't have yet in the background while you play. The wiki's text is under CC BY-NC-SA 3.0: it stays on your computer, with each passage's page and licence. Details: docs/KNOWLEDGE.md.
