An early preview

Kindred Spirit runs on Minecraft Java 1.21.1 with Fabric. Hosting Pip (her brain, AI and voice) is set up for macOS today; Linux should work but hasn't been tried, and Windows hosts are on the roadmap. Friends who join a host's world can be on Windows and need only the mod.
