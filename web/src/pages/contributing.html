Help build her

Kindred Spirit is young, and small contributions shape it a lot. Contribute, playtest and send feedback, however you like: any help is appreciated. You don't need to know Minecraft modding: half of the project is Python. Skins and blueprints to share are welcome too.

  • Contributing guideHow the project is laid out, how to set it up, common tasks, and what to check before a pull request.
  • Contributor agreementRead and sign it before your first pull request is merged (a comment on the pull request is enough).
  • Rules for AI agentsUsing an AI coding assistant? Point it at AGENTS.md: the rules it must follow here.
  • Good first issuesIdeas sized for a first contribution.

Playtesting counts

Trying her and saying how it went helps as much as code, especially where nobody has been yet: a real Intel Mac, the Setup's first-run warning, real AI keys, an update from one release to the next. Open an issue with the Setup's "Copy a help prompt" text, or the terminal output. How the project tests itself on every system: docs/TESTING-PLATFORMS.md.

Ground rules

  • The player's world stays theirs. The mod adds no blocks, items, entities or world generation, and never writes to world saves. Anything that changes the world is something the player asked for, and it can be switched off.
  • Light on the game. Nothing heavy on the game's threads; network and AI calls never block it.
  • Cozy, with a personality. Pip can be cheeky, sulky or annoyed, but never cruel, and nothing for players of all ages to worry about.
  • Tests with every change, and a line in the changelog.
  • Be kind in issues and reviews. The project follows the Contributor Covenant.

Licence and the agreement, in short

The code is under the GNU AGPL-3.0. With the contributor agreement you keep the copyright of what you write, your contribution is published to everyone under the AGPL-3.0, and you also give the maintainer the right to license it under other terms. The agreement itself is what counts: CLA.md.

If you used AI tools for a contribution, say so in the pull request. This project is itself written with Claude Code; see Credits.

Please report it privately, not in a public issue: SECURITY.md says how.
