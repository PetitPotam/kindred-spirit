# The tour: Pip's journey with a player, from strangers to old friends, and everything she can do.
# Filmed by the sandbox game itself on a floating meadow built at the start. From the mod folder,
# with the brain running (scripts/start.sh):
#   ../brain/.venv/bin/python ../demo/seed_journey.py      (her memories "weeks later", made up)
#   ../brain/.venv/bin/python ../demo/make_voices.py t_    (the player's lines)
#   ./gradlew runClient -PdevScript=../demo/tour-script.txt -PvideoSize=960x540
#   ../demo/.venv/bin/python ../demo/make_video.py tour
# Each "mark X" ... "mark X_end" is a chapter; "caption" puts a note at the bottom of the edit.
# Pip's answers are live (real speech-to-text and AI), so every take is a little different.
# part 1 is filmed in its own world (a first meeting); part 2 in another, later play session, where she
# remembers a longer journey (prepared by seed_journey.py) brought in with /kindred memory import.
