# The singleplayer showcase: what Pip can do and how she's used (with a word about LAN at the end).
# Filmed by the sandbox game itself on a floating meadow built at the start. From the mod folder,
# with the brain running (scripts/start.sh):
#   ../brain/.venv/bin/python ../demo/make_voices.py s_    (the player's lines)
#   ./gradlew runClient -PdevScript=../demo/showcase-script.txt -PvideoSize=960x540
#   ../demo/.venv/bin/python ../demo/make_video.py showcase
# Each "mark X" ... "mark X_end" is a chapter; "caption" puts a note at the bottom of the edit.
# Pip's answers are live (real speech-to-text and AI), so every take is a little different.
