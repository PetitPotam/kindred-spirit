# Code of conduct

Kindred Spirit follows the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)**:
be welcoming, kind and patient; no harassment, insults, sexual content or personal attacks, in issues,
pull requests, discussions or anywhere the project is represented. Pip is for players of all ages:
please keep it that way.

**Reporting:** contact the maintainer, [PetitPotam](https://github.com/PetitPotam), through GitHub (for something
that must stay private, see how in [SECURITY.md](SECURITY.md)). Reports are handled confidentially. The
maintainer may remove comments, issues or contributions, and block people, who don't follow this code.
